INTRODUCTION TO CSS:

What is CSS?

  • CSS stands for Cascading Style Sheets.
  • It is used to style and format HTML documents by controlling how elements appear on a webpage.
  • With CSS, you can change colors, fonts, spacing, layout, and even add animations.

Why use CSS?

  • Separation of content and design – HTML handles structure, CSS handles styling.
  • Reusability – The same CSS file can be applied to multiple web pages.
  • Consistency – Ensures a uniform look and feel across all pages.
  • Faster development – Reduces code duplication in HTML.
  • Responsive design – Helps adapt layouts for mobiles, tablets, and desktops.

Types of CSS

  1. Inline CSS – Written directly in the HTML element using the style attribute.
  2. Internal CSS – Written inside a style tag in the head section of an HTML file.
  3. External CSS – Written in a separate .css file and linked with link
